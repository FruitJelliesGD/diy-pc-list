# 🖥️ PC 配置单

一个轻量、零依赖的 PC 硬件配置清单管理工具。单个 HTML 文件，浏览器直接打开即可使用。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| **配件管理** | 添加、编辑、删除配件（类别、型号、单价、数量） |
| **多重配置** | 支持多标签页管理多套配置单，可新建、重命名、删除配置 |
| **捆绑管理** | 自由选择任意配件组成捆绑组，组合显示总价，支持编辑与解绑 |
| **拖拽排序** | 桌面端拖拽 + 移动端长按拖动调整配件顺序 |
| **预算追踪** | 设置总预算，实时显示进度条与剩余/超出金额 |
| **深色/浅色主题** | 支持跟随系统、强制深色、强制浅色三种模式，一键切换 |
| **导入** | 支持从剪贴板导入 Markdown 表格、选择 CSV 文件导入（含捆绑组信息），导入前可预览 |
| **导出** | 导出为 CSV 文件（含捆绑组信息） |
| **复制** | 一键复制为 Markdown 表格（含捆绑组信息） |
| **分享** | 生成精美分享图片 + 通过 URL 哈希分享配置链接 |
| **打印** | 专用打印样式，隐藏操作按钮，干净输出 |
| **快捷键** | 支持 `Ctrl+N`、`Ctrl+E`、`Ctrl+I`、`?` 等快捷键，弹窗帮助 |
| **数据持久化** | 所有数据自动保存至 `localStorage`，支持旧版数据迁移 |
| **响应式** | 适配桌面与移动端，触摸友好 |

## 🚀 使用方式

直接在浏览器中打开 `index.html` 即可，无需安装任何依赖。

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## 📖 使用指南

### 基本操作

1. **添加配件** — 在顶部输入配件名称、型号和单价，点击「＋ 添加」或按 `Enter`
2. **编辑** — 点击型号或价格列可直接内联编辑，焦点移出或按 `Enter` 确认，`Esc` 取消
3. **调整数量** — 使用行内的 `＋` / `－` 按钮，或编辑总价自动反算单价
4. **拖拽排序** — 桌面端：悬停行首拖拽手柄（⠿）拖动；移动端：长按行首后拖动
5. **设置预算** — 在底部预算栏输入金额，实时查看剩余/超出情况
6. **编辑标题** — 点击顶部标题可直接编辑配置单名称

### 捆绑管理

- 点击底部「🔗 捆绑」按钮打开捆绑管理弹窗
- 在「新建捆绑组」中勾选配件，点击确认捆绑
- 捆绑后的配件会排列在一起，组合显示总价
- 点击捆绑组总价可编辑总价，自动按数量比例分配
- 可在弹窗中解绑已有捆绑组

### 多重配置

- 顶部标签栏显示所有配置，点击切换
- 点击「＋」新建配置，双击标签重命名，悬停显示关闭按钮
- 每个配置独立存储名称、配件列表和预算

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 新建配件（聚焦输入框） |
| `Ctrl + Shift + N` | 新建配置标签 |
| `Ctrl + Shift + C` | 复制 Markdown 表格 |
| `Ctrl + E` | 导出 CSV |
| `Ctrl + I` | 导入 |
| `Ctrl + P` | 打印 |
| `?` | 快捷键帮助 |
| `Esc` | 关闭弹窗 |

### 导入/导出

- **导入** — 点击「📥 导入」，支持从剪贴板粘贴 Markdown 表格或选择 CSV 文件
- **导出** — CSV 格式，含捆绑组列信息
- **复制** — 一键复制为 Markdown 表格（含捆绑信息）
- **分享** — 生成分享图片（Canvas 绘制，适配主题色）或复制 URL 链接（Base64 编码于 URL 哈希中）

## 🏗️ 技术细节

- **纯原生** — HTML + CSS + Vanilla JavaScript，无框架、无构建工具
- **CSS 变量** — 通过 `:root` + `@media (prefers-color-scheme)` + `data-theme` 属性实现三级主题切换
- **Canvas API** — 分享图片通过 Canvas 绘制，支持深色/浅色两种样式，列宽动态计算
- **structuredClone** — 使用现代 API 深拷贝对象
- **本地存储** — 数据存储键 `pc_config_v11`，支持旧版单配置数据自动迁移
- **URL 哈希** — 配置数据 Base64 编码后存入 URL `#` 部分，支持分享链接
