# 🖥️ PC 配置单

一个轻量、零依赖的 PC 硬件配置清单管理工具。单个 HTML 文件，浏览器直接打开即可使用。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| **配件管理** | 添加、编辑、删除配件（类别、型号、单价、数量） |
| **可编辑标题** | 顶部标题支持内联编辑，自动保存至本地 |
| **主题切换** | 支持跟随系统 / 浅色 / 深色三种模式，选择持久化 |
| **自定义捆绑** | 任意配件可自由组合为捆绑组，组内配件排列在一起、合计显示总价 |
| **拖拽排序** | 拖拽行调整配件顺序 |
| **预算追踪** | 设置总预算，实时显示进度条与剩余/超出金额 |
| **导入** | 支持从剪贴板导入 Markdown 表格、选择 CSV 文件导入，导入前可预览 |
| **导出** | 导出为 CSV 文件（含捆绑组信息） |
| **复制** | 一键复制为 Markdown 表格（含捆绑组信息） |
| **分享** | 生成精美分享图片，支持复制到剪贴板或下载 |
| **数据持久化** | 所有数据、标题、主题选择自动保存至 `localStorage` |
| **响应式** | 适配桌面与移动端 |

## 🚀 使用方式

直接在浏览器中打开 `index.html` 即可，无需安装任何依赖。

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## 📖 使用指南

1. **添加配件** — 在顶部输入配件名称、型号和单价，点击「＋ 添加」
2. **编辑** — 点击型号或价格列可直接内联编辑
3. **调整数量** — 使用行内的 `＋` / `－` 按钮
4. **拖拽排序** — 将鼠标悬停至行首拖拽手柄（⠿），拖动调整顺序
5. **自定义捆绑** — 点击「🔗 捆绑」按钮，勾选需要捆绑的配件，组合显示并合计总价
6. **设置预算** — 在底部预算栏输入金额，实时查看剩余/超出情况
7. **导入数据** — 点击「📥 导入」，支持从剪贴板粘贴 Markdown 表格或选择 CSV 文件
8. **导出/分享** — 使用底部按钮复制、导出 CSV 或生成分享图片
9. **修改标题** — 直接点击顶部标题文字进行编辑，按 Enter 或失焦保存
10. **切换主题** — 点击标题旁的 🌙/☀️ 按钮，循环切换系统跟随 / 浅色 / 深色

## 🏗️ 技术细节

- **纯原生** — HTML + CSS + Vanilla JavaScript，无框架、无构建工具
- **CSS 变量** — 通过 `:root` 变量 + `@media (prefers-color-scheme)` 实现基础主题，手动切换通过 `.dark-mode` / `.light-mode` 类覆盖
- **Canvas API** — 分享图片通过 Canvas 绘制，支持深色/浅色两种样式
- **存储** — 数据存储键 `pc_config_v10`，预算存储键 `pc_budget_v1`，标题存储键 `pc_title_v1`，主题存储键 `pc_theme_v1`
